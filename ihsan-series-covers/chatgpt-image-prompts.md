# ChatGPT image prompts for the cover illustrations

Paste one prompt per chat. For tighter results, attach the matching `preview/book-N-...-front.png` and add:
"Use the attached cover only as a composition reference for the circle illustration."
Save each result as `art/book-N.png` (square), then run `node build.js`. The circle crop is automatic.
